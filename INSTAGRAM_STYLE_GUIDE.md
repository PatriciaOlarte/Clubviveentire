# Guia visual de Instagram - Club Vive Entire

Perfil revisado:

https://www.instagram.com/clubviveentire/

## Identidad actual

La cuenta ya tiene una linea visual clara:

- Logo Entire visible y reconocible.
- Paleta principal azul oscuro, turquesa, blanco y celeste.
- Enfoque educativo: datos practicos, mitos, senales, habitos y guias.
- Uso frecuente de producto en empaque real.
- Fotografias de adultos mayores, familias y ninos.
- Iconos lineales para reforzar beneficios.
- Titulares grandes en mayusculas o alto contraste.
- Historias destacadas con iconos simples: guia, beneficios, calculadoras.

## Lo que conviene mantener

- El enfoque de nutricion inteligente para cada etapa de vida.
- La presencia del producto en cada pieza comercial.
- Los colores institucionales: azul oscuro, turquesa y blanco.
- Titulares directos tipo pregunta o dato.
- El estilo educativo: ayuda a crear confianza antes de vender.
- Los iconos de apoyo para beneficios o pasos.

## Ajustes recomendados para vender mas

1. Reducir texto en la primera lamina.

La portada debe tener una sola idea principal. El detalle puede ir en laminas internas del carrusel o en el copy.

2. Usar CTA visible en todas las piezas.

Ejemplos:

- Descubre cual Entire es para ti.
- Haz el quiz.
- Pide asesoria por WhatsApp.
- Compara las formulas.

3. Conectar cada pieza con la landing.

Cada publicacion debe llevar a:

https://landing.entirenutricion.net/

Usar siempre enlaces UTM segun canal.

4. Crear una estructura fija para carruseles.

Lamina 1: pregunta o problema.

Lamina 2: contexto educativo.

Lamina 3: senales o pasos.

Lamina 4: producto recomendado o comparacion.

Lamina 5: CTA hacia quiz, WhatsApp o compra.

5. Separar piezas por etapa de vida.

- Adultos 40+: Master.
- Control de azucar: Zero.
- Actividad fisica/proteina: Proteina.
- Ninos: Kido.
- Rutina diaria: Full.

## Reglas visuales para nuevas piezas

- Mantener fondo claro o celeste suave.
- Usar azul oscuro para titulares principales.
- Usar turquesa para llamadas, etiquetas y botones.
- Evitar saturar la lamina con mucho texto.
- Dejar el producto grande y limpio cuando el objetivo sea venta.
- Usar fotografias humanas cuando el objetivo sea identificacion emocional.
- Usar iconos cuando el objetivo sea explicar beneficios.
